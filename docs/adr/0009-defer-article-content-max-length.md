# 0009. 게시글 본문 최대 길이는 에디터 도입 시 정한다

- 상태: 보류
- 날짜: 2026-10-08

## 배경
리뷰에서 게시글 본문(`content`)에 길이 제한이 없다는 지적이 있었다. 1만 자 제한을 검토했다.

## 결정
지금은 `CreateArticleDto.content`에 `@MaxLength`를 두지 않는다.

## 근거
- 리치 에디터를 붙이면 서식(HTML/JSON) 때문에 저장 크기가 보이는 글자보다 몇 배 커진다.
  저장 형식을 정하기 전에 숫자를 정하면 곧 바꿔야 한다.
- JSON 요청 본문 기본 제한 **100KB**(body-parser 기본값 102400바이트)가 이미 상한 역할을 한다.
  초과 시 **413**으로, 500이 아니다 (90,000바이트 → 정상 처리, 110,000바이트 → 413 직접 확인).

## 결과
에디터 도입 시 함께 정할 것:
- 글자 수가 아닌 **바이트 기준** 제한
- 이미지를 본문에 base64로 넣지 않기 (업로드 API로 분리하고 본문에는 주소만)
- 긴 글이 필요하면 요청 크기 제한을 **게시글 API에만** 올리는 방식
- HTML 저장 시 XSS 방어
